# 🌸 Waguri OS

A anime-inspired desktop operating system built entirely with **HTML, CSS, and JavaScript**.

Waguri OS recreates the experience of a real desktop operating system inside a web browser. It features a boot sequence, user login, draggable windows, a taskbar, desktop icons, wallpaper customization, a file explorer, a photo viewer, notifications, and much more.

## 🛠️ How It Works

Waguri OS is built entirely with vanilla HTML, CSS, and JavaScript without using frameworks.

Instead of relying on external UI libraries, every desktop component, including windows, the taskbar, boot screen, notifications, wallpaper manager, and desktop applications, is created from scratch.

Windows are dynamically controlled using JavaScript, allowing them to be opened, minimized, closed, dragged around the desktop, and layered using z-index management. User preferences, such as usernames and wallpapers, are stored locally using the browser's Local Storage so the desktop remembers settings between sessions.

This lightweight approach keeps the project fast while demonstrating how a desktop-like operating system can be recreated using only standard web technologies.
